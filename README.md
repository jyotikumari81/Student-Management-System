Student Management System

About the Project

The Student Management System is a Java-based project designed to manage student information efficiently.

Features

- Add Student
- View All Students
- Manage Student Records

Technologies Used

- Java
- JDBC (if configured)
- MySQL (if configured)

Project Files

- "Main.java" – Main program
- "Student.java" – Student details
- "StudentDAO.java" – Student data operations
- "DBConnection.java" – Database connection
